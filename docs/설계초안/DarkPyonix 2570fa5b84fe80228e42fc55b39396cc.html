1. Kernel Manager

2-A. Kernel

class Kernel:
    kernel_id: str
    status: str  #  "running" | "interrupted"
  • 커널이 파일과 논리 커널로 분리되어 커널이 지워지면 토큰은 보관되나, 파일이 지워지면 토큰도 지워져야 함
  • 공유 버튼을 눌렀다가 다시 해제하고 다시 누르는 경우 토큰 초기화 필요

class File:

3. Cell

class Cell:
	id: str
	(index: int 클라이언트쪽 전송용)
	cell_type: str
	source: str
	execution_count: int
	outputs: list[dict]
	locked: bool = False
	authorized_to: Optional[str] = None
	focused_by: list[str] = []
	status: str = "none"| "pending" | "running" | "completed" | "failed"
	auto_run
	collapsed
	title
	layout - horizontal

class Notebook:

execution

class Execution:
    cell_id: str          # 실행된 셀 ID
    kernel_id: str        # 커널 ID
    code: str             # 실행된 코드
    status: Optional[Executionstatus]        # "pending" | "running" | "completed" | "failed" 
    started_at: datetime  # 실행 시작 시간
    completed_at: Optional[datetime]  # 실행 완료 시간
    outputs: list[dict]   # 실행 결과
    error: Optional[dict] # 오류 정보

ExecutionStatus

class ExecutionStatus(StrEnum):
    PENDING     = "pending"
    RUNNING     = "running"
    COMPLETED   = "completed"
    FAILED      = "failed"
