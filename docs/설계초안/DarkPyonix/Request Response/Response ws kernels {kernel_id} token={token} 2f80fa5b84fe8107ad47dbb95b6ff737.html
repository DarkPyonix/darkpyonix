클라이언트 → HTTP POST /kernels/{kernel_id}/execute
→ 서버가 코드 실행 시작
→ 서버가 실행 과정을 WebSocket으로 모든 클라이언트에 브로드캐스트

실행 시작 알림:

{
"type": "execution_started",
"cell_id": "cell_uuid",
"execution_id": "exec_123",
"started_by": "user_identifier",
"user_name": "사용자A",
"code": "for i in tqdm(range(100)): time.sleep(0.1)",
"timestamp": "2025-07-27T10:36:00Z"
}
