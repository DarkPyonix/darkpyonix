허브

darkpyonix.dev

허브는 내 컴퓨터끼리, 그리고 공유받은 사람과 내 컴퓨터를 이어 줍니다. 연결을 전달할 뿐 커널을 돌리지 않습니다. 이 페이지의 내용은 모두 계획입니다.

하는 일 계획 #21

  • GitHub 로그인과 내 기기 목록.
  • 컴퓨터 사이의 연결 중개와 중계: 가능하면 NAT를 넘어 직접 잇고, 안 되면 중계합니다.
  • 공유 커널을 ash로 여는 공유 링크.
  • 전용 매니저의 HTTPS 이름.
  • 공유 노트북 ash 호스팅.

호스트 계획 #41

역할을 호스트에 어떻게 나눌지는 PR #41의 초안이며, 관리자 승인을 기다립니다. 초안은 다음과 같습니다.

호스트내용
darkpyonix.dev/메인 페이지와 ash 웹 앱. darkpyonix-ash가 빌드합니다.
darkpyonix.dev/<repo>/이 가이드 같은 프로젝트 가이드. 옮기지 않습니다.
api.darkpyonix.dev허브 API: 로그인, 기기, 주소 디렉터리, 공유, 이름.
relay.darkpyonix.dev컴퓨터 사이 연결의 중계 서버.

허브가 보는 것

허브는 두 끝을 이어 줍니다. 내용은 두 끝 사이에서 암호화하도록 설계하고 있어서(SPEC NFR-H1) 허브는 코드나 출력을 읽지 않습니다. 초안에서 공유 링크는 토큰을 URL 프래그먼트에 둡니다. 브라우저는 프래그먼트를 서버에 보내지 않습니다.

지금 되는 것

허브는 아직 운영하지 않습니다. 지금 다른 컴퓨터의 커널에 닿으려면 그 컴퓨터에서 전용 매니저를 띄우고 (darkpyonix manager --dedicated --host ... --port ...), VPN처럼 이미 믿을 수 있는 네트워크로 접근합니다.
